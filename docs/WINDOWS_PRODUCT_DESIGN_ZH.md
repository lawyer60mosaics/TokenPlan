# TokenPlan Windows 界面设计说明

## 桌面端导航结构

Windows 主窗口采用左右双栏布局。左侧菜单始终显示“套餐概览、套餐管理、云端同步、定时任务、通知配置、云平台、使用帮助”，右侧只呈现当前选择的功能，避免设置项堆叠在同一个弹窗中。默认窗口为 1040 × 760，缩小窗口时菜单会保留图标并自动隐藏文字。

## 通知配置

支持钉钉自定义机器人和企业微信群机器人。每个渠道均可单独启用、填写 Webhook 并发送测试消息；成功通知和失败通知可以分别控制。桌面端只允许向官方 HTTPS 域名发送机器人请求，Webhook 由 Windows DPAPI 加密保存。

## 云平台

可以选择 GitHub Actions、阿里云函数计算 FC 或腾讯云云函数 SCF。阿里云和腾讯云凭据独立保存在本机，不跟随套餐配置上传；界面明确提示费用风险，并建议使用最小权限子账号。

Windows 端与 iOS 端使用同一套信息层级，但保留桌面窗口、键盘操作和鼠标悬停反馈。

## 套餐首页

- 顶部总览显示启用数量、正常数量、异常数量和最近刷新时间。
- 常用操作固定提供“全部刷新、添加套餐、同步设置”三个中文入口。
- 套餐卡显示供应商、套餐名称、状态文字、用量进度和更新时间。
- 没有套餐时显示三步入门流程，不要求用户先理解设置页面。

## 套餐设置

- 第一步填写供应商、名称和站点。
- 第二步填写凭据，每个字段说明凭据来源和用途。
- 第三步设置自动查询、开机启动，并说明 DPAPI 加密规则。
- 套餐选择器固定在设置页顶部，多个套餐之间可以快速切换。

## 云同步与定时任务

- 云同步账号与套餐供应商账号明确分离。
- 下载、上传和停用都显示操作影响并要求确认。
- 新设备优先下载，本机修改后再上传。
- 配额预热注明会产生真实调用，并提醒 GitHub、阿里云和腾讯云只能启用一个调度平台。

## 视觉与无障碍

- 使用 Segoe UI Variable、系统语义色、分组表单和圆角卡片。
- 主要按钮提供不低于 44px 的操作区域。
- 支持系统深色模式、高对比度和减少动态效果设置。
- 状态不只依赖颜色，同时提供文字和图标。
- 所有图标按钮具备可读的中文或英文辅助标签。
